1. Runtime (ช่วงเวลาเดินเครื่อง)
ความหมาย: ตอนที่คุณกำลังนั่งพิมพ์โค้ด Python หรือ React โค้ดพวกนั้นเป็นแค่ตัวหนังสือธรรมดานอนนิ่งๆ แต่ทันทีที่คุณกดปุ่มรัน หรือพิมพ์คำสั่งเริ่ม
