# สารบัญเอกสารอ้างอิงโรงปืน (Armory Document Reference Index)
หน่วย: ป.๔ พัน.๔ ร้อย.๒ (กองร้อยทหารปืนใหญ่ที่ ๔)

คลังเอกสารอ้างอิง (Ref.) นี้รวบรวมเอกสารราชการทหาร สายสรรพาวุธ (สพ.) และระเบียบสารบรรณ ทบ. ทั้งหมด แบ่งออกเป็น ๓ หมวดหลัก:

---

## ๑. หมวดเอกสารต้นฉบับประจำหน่วย (01_เอกสารต้นฉบับหน่วย_Original_PDF_and_XLSX)
เอกสารจริงที่ใช้ปฏิบัติงานในกองร้อย:
- บัญชีหมายเลขอาวุธล่าสุด (ทบ. ๔๖๘-๒๐๔ / คส. ๔)
- ทบ. ๔๖๘-๓๖๐ กำหนดการปรนนิบัติบำรุง ๓๑ วัน
- บันทึกข้อความขอส่งใบติดตามทวงถาม ๔๕ วัน และ ๙๐ วัน
- บัญชีรายละเอียดหมายเลข ปบค.๙๕ (๑๐๕ มม.)
- ใบติดตามใบส่งซ่อมแบบ ข (ทบ. ๔๐๐-๐๗๑)
- สมุดบันทึกการเบิก-รับ ลูกกุญแจ คลังโรงปืน (XLSX)
- สมุดบันทึกการรับกุญแจ คลังอาวุธ (XLSX)
- บัญชีสถานภาพอาวุธที่แจกจ่ายให้กองร้อย (XLSX)
